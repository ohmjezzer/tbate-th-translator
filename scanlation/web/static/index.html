    แก้ไขบอลลูน

    (ขยับ 2px, Shift = 10px)

    ลากกรอบในภาพเพื่อย้ายข้อความ · ลากมุมขวาล่างเพื่อปรับกรอบ · ปุ่ม Delete = ลบ

    📖 วิธีใช้งานหน้า Preview

    หน้านี้ใช้ตรวจและแก้ผลการแปลก่อนส่งงาน — ทุกอย่างแก้ได้ด้วยเมาส์

    ✋ 1) เลือก / ย้ายบอลลูน

    1. คลิกบอลลูนในภาพเพื่อเลือก (กรอบจะเปลี่ยนเป็นสีเขียว)
    2. ลากตัวกรอบเพื่อย้ายตำแหน่ง · ลากมุมขวาล่างเพื่อปรับขนาด
    3. แก้คำแปลในช่องด้านขวา · ปรับฟอนต์/สี/จัดชิดได้
    4. ลบบอลลูน: กดปุ่ม Delete หรือปุ่ม 🗑

    🖌 2) แปรงลบพื้นหลัง / ข้อความตกค้าง

    1. เลือกเครื่องมือ "แปรงลบพื้นหลัง" แล้ว วาดทับส่วนที่อยากลบ (จะเห็นสีแดง)
    2. กด 🪄 ลบพื้นที่ที่แปรง (AI) → AI จะลบให้เนียน
    3. กด ↶ Undo ลบ เพื่อย้อนกลับได้ทันที
    4. วาดผิด? ใช้ 🧽 ลบเส้นที่แปรง หรือ ↶ ลบเส้นล่าสุด ก่อนกดลบจริง
    💡 ถ้าลบแล้วได้ไม่เนียน ลองแปรงให้คลุมตัวอักษรกว้างขึ้นเล็กน้อย แล้วลบใหม่

    ➕ 3) เพิ่มบอลลูน (กรณีระบบจับข้อความไม่เจอ)

    1. เลือกเครื่องมือ "เพิ่มบอลลูน" แล้ว ลากวาดกรอบครอบข้อความที่ตกหล่น
    2. ติ๊ก "ลบข้อความเดิมในกรอบ (AI)" เพื่อให้ระบบลบอังกฤษเดิมให้อัตโนมัติ
    3. จากนั้นพิมพ์คำแปลไทยในช่องด้านขวาได้เลย

    ⌨️ คีย์ลัด

    • 1 เลือก/ย้าย · 2 แปรง · 3 เพิ่มบอลลูน
    • Ctrl+S บันทึก · Ctrl+Z ลบเส้นแปรงล่าสุด
    • Esc ยกเลิกการวาด · Delete ลบบอลลูนที่เลือก
