# 🖼 Preview UI — เครื่องมือตรวจ/แก้ผลการแปล (ปรับปรุงให้ใช้งานง่าย)

รันหน้าเว็บ: `python -m scanlation.cli preview` → http://127.0.0.1:8000

## ปัญหาที่แก้ในรอบนี้

| อาการ | สาเหตุที่พบ | การแก้ |
|---|---|---|
| **กด "เพิ่มบอลลูน" แล้วลากวาดไม่ได้เลย** | CSS เปิด `pointer-events` ของ `<canvas>` เฉพาะโหมด `brushing` แต่ **ไม่เปิดในโหมด `adding`** → เมาส์ไม่ถึง canvas เลย | เพิ่ม `.stage-inner.adding .brush-canvas { pointer-events: auto; }` |
| **แปรงลบแล้วได้ผิดตำแหน่ง / ไม่ตรงที่วาด** | พิกัดอ้างอิงจากกรอบ `<canvas>` ซึ่งอาจไม่ตรงกับรูปที่แสดงจริง (รูปถูกย่อ หรือสลับ view `out/cleaned/orig` ที่ขนาดต่างกัน) | เปลี่ยนเป็นยึด **กรอบของ `<img>` + ขนาดจริง (`naturalWidth/Height`)** เป็นมาตรฐานเดียว ผ่านฟังก์ชัน `toImageXY()` / `scaleXY()` |
| **UI ไม่ friendly** | ไม่มีคำแนะนำว่าต้องทำอะไรต่อ, เครื่องมือแปรงไม่ครบ (วาดผิดแล้วแก้ไม่ได้), ไม่มีคู่มือ | เพิ่ม **แถบสถานะ**, **ปุ่มลบเส้นที่แปรง / ลบเส้นล่าสุด**, **วงกลมแสดงขนาดแปรง**, **ม็อดัลช่วยเหลือ**, **คีย์ลัด** |

## เครื่องมือในหน้า Preview

### ✋ เลือก/ย้าย
คลิกบอลลูน → ลากย้าย · ลากมุมขวาล่างปรับขนาด · แก้คำแปล/ฟอนต์/สี/จัดชิด · ปุ่ม `Delete` ลบ

### 🖌 แปรงลบพื้นหลัง / ข้อความตกค้าง
- วาดทับส่วนที่อยากลบ (เห็นสีแดง) → กด **🪄 ลบพื้นที่ที่แปรง (AI)**
- **🧽 ลบเส้นที่แปรง** — สลับเป็นโหมดลบเส้น แล้วคลิกทับเส้นที่วาดผิด (หรือคีย์ `E`)
- **↶ ลบเส้นล่าสุด** — ลบทีละเส้น (`Ctrl+Z`)
- **↶ Undo ลบ** — ย้อนผลการลบที่ทำไปแล้วกลับ

### ➕ เพิ่มบอลลูน (กรณีระบบจับข้อความไม่เจอ)
ลากวาดกรอบครอบข้อความที่ตกหล่น → ติ๊ก **"ลบข้อความเดิมในกรอบ (AI)"** เพื่อลบอังกฤษเดิมให้อัตโนมัติ แล้วพิมพ์คำแปลได้เลย

## คีย์ลัด
`1` เลือก · `2` แปรง · `3` เพิ่มบอลลูน · `E` สลับโหมดลบเส้น · `Ctrl+S` บันทึก · `Ctrl+Z` ลบเส้นแปรงล่าสุด · `Esc` ยกเลิกการวาด/ปิดคู่มือ · `Delete` ลบบอลลูนที่เลือก

## API ที่เพิ่ม/ปรับ
| Endpoint | เพิ่ม |
|---|---|
| `POST /api/page/<i>/bubbles` | รับ `erase: true` → ลบข้อความเดิมในกรอบด้วย AI ทันที |
| `POST /api/page/<i>/inpaint` | รับ `op="box"` + `bbox` → ลบข้อความในกรอบ (ใช้เมื่อ detection ตกหล่น) |
